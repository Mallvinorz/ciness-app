# ciness-app

Ciness is a movie application to show all information about movies

## Connect with TMDB API

Add this to your local.properties file:

API_BASE_URL="https://api.themoviedb.org/3/"
IMAGE_BASE_URL="https://image.tmdb.org/t/p/"
API_READ_ACCESS_TOKEN="" ------> Add your access token from TMBD api here
API_KEY="" ---------->> Add your api key from TMBD api here.
